# Arktec Software Solutions

A responsive, premium-style company website built with plain HTML, CSS, and JavaScript. No build step, framework, or package installation is needed.

## Preview locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a GitHub repository and upload these files to its root (`index.html`, `styles.css`, and `script.js`).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub will publish the site at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

All local asset links are relative, so the site also works when hosted under a repository path. Google Fonts are loaded from Google Fonts when online; the system font fallback remains available offline.

## Before launch

- Replace the demo dashboard concept with real work when available.
- Confirm the contact address (`hello@arktec.lk`) and update it in `index.html` if needed.
- Add the company's real social links, phone number, and legal details if desired.
